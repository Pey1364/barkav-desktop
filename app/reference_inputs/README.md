# فایل‌های مرجع محلی 18.7.1

این پوشه محل نسخهٔ محلی و فقط-خواندنی دو مرجع کاربر است:

- `تقسیم بندی کد نویسی پیشنهاد کدکس.xlsx`: فازبندی، مالکیت و مرزهای معماری.
- `مرجع مدیریت پروژه.xlsx`: الگوی ۳۲ فاز اجرایی، کاتالوگ مصالح/اجرت/خدمات و ساختار برآورد.

این فایل‌ها در زمان اجرای برنامه خودکار به SQLite وارد نمی‌شوند. ورود داده‌های واقعی
باید در یک قابلیت Import مستقل، با پیش‌نمایش، نگاشت ستون‌ها، پشتیبان‌گیری و تأیید کاربر
پیاده‌سازی شود. به‌دلیل احتمال وجود قیمت‌ها یا داده‌های پروژه، فایل‌های Excel این پوشه
عمداً در Git نادیده گرفته می‌شوند.
