# BARKAV 18.7.1

نسخهٔ بازساخت‌شده و مستقل BARKAV بر پایهٔ فرمول‌ها و داده‌مدل معتبر 18.7.

## اجرا

1. Python 3.10 یا جدیدتر نصب باشد.
2. وابستگی‌ها را نصب کنید: `python -m pip install -r requirements_18_7_1.txt`
3. فایل `BARKAV_18.7.1.bat` را اجرا کنید.

ورودی اصلی فقط `barkav1871.app` است. ماژول‌های فعال از پوشهٔ
`barkav1871/` بارگذاری می‌شوند.

## ساختار

- `barkav1871/core`: هویت، پروژهٔ فعال و مسیرهای برنامه
- `barkav1871/design`: تم، فونت و کنترل‌های مشترک
- `barkav1871/services`: SQLite، فروش، پروژه، اسناد، پیمانکاران و خروجی
- `barkav1871/features`: صفحه‌های برنامه
- `barkav1871/integrations`: گردش Pending تلگرام و import تاریخچه
- `old_version/legacy_18_7`: کد و مستندات تاریخی، فقط برای مراجعه و بازگشت

دادهٔ پروژه در `data/` است و نباید همراه کد یا release commit شود.
