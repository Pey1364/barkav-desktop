# تصمیم‌های هندسه — مرجع طراحی بصری

هندسه برای هر سه تم (تاریک، روشن، رنگی) یکسان است. رنگ و آیکون جداگانه و برای هر تم تعیین می‌شود.

نمونهٔ مرجع: تب درآمد ← زیرتب قراردادها

---

## بخش ۱ — اسکلت کلی

| # | تصمیم |
|---|---|
| ۱ | دو کلمهٔ انگلیسی زیر نام لاتین در لوگو حذف شود |
| ۲ | نوار بالا و نوار پایین گردگوشه شوند |
| ۳ | هر چهار دکمهٔ بالا ارتفاعشان کم شود و کادرشان لوبیایی شود — بالا و پایین صاف، چپ و راست قوس |
| ۴ | ترتیب: لوگو سمت راست؛ از سمت چپ به ترتیب فایل، سیو، آندو، ریدو |
| ۵ | دکمه‌های نوار پایین هم لوبیایی شوند |
| ۶ | ثانیهٔ ساعت نمایش داده نشود |
| ۷ | آیکون پیام‌ها مثل آیکون پیام ویندوز ۱۰ شود |
| ۸ | دکمهٔ «تیره» به «حالت نمایش» تغییر نام دهد، با سه گزینه: تاریک، روشن، رنگی |
| ۹ | اندازهٔ آیکون‌ها ۳۰٪ بزرگ‌تر شود |
| ۱۰ | پنجرهٔ کرکره‌ای فایل چپ‌چین شود؛ اندازه و نوع فونت عناوینش با عنوان تب‌ها یکی باشد |

---

## بخش ۲ — تب‌ها و زیرتب‌ها

کاشی لوبیایی، همان شکل دکمه‌های نوار بالا. تب فعال پر، تب غیرفعال خالی.

---

## بخش ۳ — دکمه‌های قابلیت‌ها

| # | تصمیم |
|---|---|
| ۱ | لوبیایی، با آیکون و متن |
| ۲ | ارتفاعشان ۴۰٪ کم شود |
| ۳ | همه در یک سطر قرار بگیرند |
| ۴ | «خروجی» سمت راست، «نمایش بر اساس» سمت چپ، بقیهٔ دکمه‌ها وسط |

---

## بخش ۴ — جدول‌ها و کادرهای اصلی

| # | تصمیم |
|---|---|
| ۱ | گوشهٔ تمام کادرها کرو باشد |
| ۲ | خطوط عمودی و افقی حذف شوند؛ به‌جایشان دور هر **سلول** یک کادر گردگوشه با پس‌زمینهٔ متفاوت، با فاصلهٔ خیلی کم بین سلول‌ها |

**محدودیت فنی بند ۲:** `Treeview` سطر می‌کشد نه سلول، و پس‌زمینهٔ هر سلول را جداگانه نمی‌پذیرد. کاشی‌بندی سلولی یعنی جایگزینی `Treeview` با یک جدول اختصاصی روی `Canvas`. این کار شدنی است ولی باید مرتب‌سازی، انتخاب، اسکرول و تغییر عرض ستون از نو نوشته شوند.
