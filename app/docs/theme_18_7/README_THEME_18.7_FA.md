# کد تم‌های آماده برای BARKAV 18.7

## وضعیت

- **تم ۱**: Snapshot دقیق توکن‌های ظاهری نسخه ۱۸.۶؛ نسخه ۱۸.۶ فعلی تغییر نکرده است.
- **تم ۲**: کد مستقل Dark/Light بر اساس ۱۶ تصویر همین پوشه.
- این کد هنوز به مسیر اجرایی محصول وصل نشده و هیچ نسخه‌ای را ۱۸.۷ اعلام نمی‌کند.
- هیچ تغییر دیتابیس، تنظیمات کاربر، Telegram، Gemini یا منطق مالی انجام نشده است.

## فایل‌ها

- `barkav_themes/tokens.py`: تعریف تم ۱ و تم ۲، رنگ‌ها و اندازه‌ها.
- `barkav_themes/engine.py`: انتخاب تم، سازگاری با Palette فعلی ۱۸.۶ و Styleهای ttk.
- `barkav_themes/widgets.py`: هدر دوطبقه، ناوبری، کارت، Toolbar، جدول، KPI، وضعیت سرویس و اکشن‌های پایین.
- `theme_preview.py`: پیش‌نمایش مستقل صفحات داشبورد، نمودار، جدول و ثبت دیتا.
- `reference_manifest.json`: نگاشت و SHA-256 تصاویر مرجع.
- `REFERENCE_ANALYSIS.md`: قواعد بصری استخراج‌شده از تصاویر.
- `tests/test_theme_code.py`: کنترل ثبات تم ۱، کامل بودن تم ۲ و عدم تغییر تصاویر مرجع.

## اجرای پیش‌نمایش

از داخل همین پوشه:

```powershell
python theme_preview.py --theme 2 --mode dark --page dashboard
python theme_preview.py --theme 2 --mode light --page data
python theme_preview.py --theme 1 --mode dark --page table
```

صفحه‌های قابل انتخاب: `dashboard`, `report`, `table`, `data`.

## اتصال در مرحله ساخت ۱۸.۷

1. بسته `barkav_themes` به Source نسخه ۱۸.۷ منتقل شود.
2. شناسه `theme_id` فقط در تنظیمات UI ذخیره شود؛ به دیتابیس مالی یا Schema اضافه نشود.
3. به جای Palette ثابت، از `legacy_palette(ThemeSelection(theme_id, mode))` استفاده شود تا ویجت‌های ۱۸.۶ بدون بازنویسی گسترده کار کنند.
4. `apply_ttk_theme` پیش از ساخت صفحات اجرا شود.
5. هدر، ناوبری، Toolbarها، جدول‌ها و اکشن‌های پایین به‌تدریج با مؤلفه‌های `widgets.py` جایگزین شوند.
6. عنوان تب‌ها و متن‌های برنامه از کد ۱۸.۶/اصلاحات بعدی بیایند؛ متن تصاویر مرجع کپی نشود.
7. پس از دریافت اصلاحات ۱۸.۶ از کاربر، Overlay واقعی ۱۸.۷ ساخته و هر دو تم با تست Dark/Light روی Windows بررسی شود.

## بازگشت امن

چون این پوشه فعلاً مستقل است، برای لغو این کار کافی است پوشه `barkav_themes` و فایل‌های پیش‌نمایش/مستندات جدید حذف شوند. نسخه ۱۸.۶ هیچ تغییری نکرده است.
