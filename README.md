# BARKAV Field

ثبت رسید و گزارش روزانه از گوشی، با انتقال رمزشده از طریق Google Drive. برنامه‌ی دسکتاپ وقتی باز شود، ورودی‌های جدید را می‌خواند و در دیتابیس محلی خود ذخیره می‌کند.

این پروژه جدا از BARKAV 19.1.1 است و آن برنامه تغییری نمی‌کند.

## وضعیت

- بک‌اند (رمزنگاری، دیتابیس محلی، خواننده‌ی ورودی، API محلی، Google Drive، ورود دسکتاپ، عبارت عبور): ساخته شده و با ۶۹ تست پوشش داده شده. صف «در دست بررسی» (دسته‌بندی، تأیید یا رد) هم در بک‌اند آماده است؛ رابط آن در مرحله‌ی FD-07 است.
- اتصال به Google Drive: ورود با حساب تست انجام شد و یک رفت‌وبرگشت واقعی تأیید شد. تست گوشی به دسکتاپ هنوز مانده است.
- رابط کاربری (PWA و وب دسکتاپ): مرحله‌ی بعد، پس از تأیید ظاهر.
- اتصال به ۱۹.۱.۱: مرحله‌ی سوم، با تأیید.

## ورود به Google Drive (یک‌باره)

```bat
cd backend
py -3 -m barkav_field.pull signin
```

مرورگر باز می‌شود، با حساب تست وارد شو و دسترسی را بپذیر. توکن در `backend\data` ذخیره می‌شود و در Git نیست.

برای خواندن ورودی‌های جدید:

```bat
py -3 -m barkav_field.pull
```

## عبارت عبور (یک‌بار روی این رایانه)

```bat
cd backend
py -3 -m barkav_field.pull set-passphrase
```

عبارت را در ترمینال خودت تایپ کن، دو بار. بعد از آن `pull` بدون پرسش آن را می‌خواند. عبارت در مخزن رمز ویندوز می‌ماند و در فایل یا Git نوشته نمی‌شود. اگر عبارت را گم کنی، داده‌های رمزشده قابل خواندن نیستند؛ جای امنی یادداشتش کن.

## اجرای تست‌ها

```bat
cd backend
py -3 -m pip install -r requirements.txt
py -3 -m pytest tests -q
```

## آزمایش رفت‌وبرگشت با Google Drive (توسعه‌دهنده)

```bat
cd backend
py -3 -m tools.send_test_entry
```

یک ورودی آزمایشی رمزشده (با عبارت عبور تصادفی) را به پوشه‌ی ورودی آپلود می‌کند، با همان مسیر `pull` در دیتابیس موقت می‌خواند و فایل را به سطل زباله‌ی Drive می‌برد. دیتابیس واقعی تغییر نمی‌کند. فایل از سطل زباله قابل بازیابی است.
