# ADR-0003: رابط کاربری

- **وضعیت:** پیشنهادی (منتظر تأیید ظاهر)

## تصمیم

یک برنامه‌ی React با Vite به‌صورت PWA. همان کد برای گوشی (نصب‌شونده) و صفحه‌ی وب دسکتاپ استفاده می‌شود.

## دلیل

- یک کد برای دو جا، و امکان تبدیل به اپ اندروید بعداً بدون بازنویسی.

## باز

- ظاهر دقیق: کاربر یک مرجع بصری (سایت یا تصویر) می‌فرستد. تا آن زمان پیش‌نمایش تیره و مدرن با گرادیان و شیشه‌ای ساخته می‌شود.
