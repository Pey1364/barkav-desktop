# ADR-0002: بک‌اند و دیتابیس

- **وضعیت:** پذیرفته‌شده (۲۲ مهر ۱۴۰۵)

## تصمیم

بک‌اند با FastAPI و دیتابیس SQLite جدا از ۱۹.۱.۱ ساخته می‌شود. تصاویر به‌صورت فایل در پوشه‌ی داده ذخیره می‌شوند و دیتابیس فقط مسیر آن‌ها را دارد.

## دلیل

- SQLite برای یک کاربر کافی است و نیاز به سرور دیتابیس ندارد.
- FastAPI تست آسان و مستندات خودکار دارد.

## پیامد

- در صورت نیاز به چند کاربر، باید به یک دیتابیس سرور مهاجرت کرد. فعلاً لازم نیست.
