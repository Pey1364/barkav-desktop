# ADR-0009: صفحه‌ی دسکتاپ محلی برای بازبینی و تأیید

- **وضعیت:** پذیرفته‌شده (۲۴ مهر ۱۴۰۵، ۲۰۲۶-۱۰-۱۶). اتصال به ۱۹.۱.۱ جداگانه و بعد از انتقال ۱۹.۱.۱ (FD-08) است.
- **حوزه:** صفحه‌ی وب دسکتاپ (بخشی از FD-07)، API محلی (FD-03/FD-04)، صف بازبینی (FD-12).
- **وابسته به:** ADR-0006 (صف و تأیید)، ADR-0007 (ثبت سند).

## زمینه

تأیید از داخل برنامه‌ی دسکتاپ خواسته شده است. دسته‌بندی سند ثبت‌سریع و تأیید یا رد باید از کامپیوتر هم ممکن باشد، بدون اینکه ۱۹.۱.۱ تغییر کند.

## تصمیم

1. **سرور محلی:** `backend/barkav_field/server.py` همان API را روی `127.0.0.1:8765` اجرا می‌کند و فقط برای مبداهای صفحه‌ی دسکتاپ (`localhost` و `127.0.0.1` روی پورت‌های ۵۱۷۳ و ۴۱۷۳) CORS دارد.
2. **همان فرانت‌اند:** صفحه‌ی `desktop.html` در همان پروژه‌ی `frontend` ساخته می‌شود و با همان طراحی کار می‌کند. هیچ داده‌ای جز از سرور محلی خوانده نمی‌شود.
3. **داده‌ی محلی:** سرور از `backend/data` می‌خواند، مگر اینکه `BARKAV_FIELD_DATA_DIR` تنظیم شده باشد (برای تست و نمایش).
4. **عکس‌ها:** از مسیر `GET /api/v1/documents/{id}/images/{n}` خوانده می‌شوند. مسیر فایل فقط از پایگاه‌داده گرفته می‌شود.
5. **انتشار به گوشی:** تصمیم دسکتاپ در صف خروجی (`outbox`) ثبت می‌شود و `pull` آن را به‌صورت پاکت `review_status` رمزشده به Drive می‌فرستد. گوشی آن را می‌خواند. ارسال فقط با `pull` انجام می‌شود، نه خودکار.
6. **تأیید از دسکتاپ** همان قاعده‌ی ADR-0006 را دارد: تصمیم اول برنده است و هیچ ردیف مالی ساخته نمی‌شود. صفحه صریحاً می‌گوید که تأیید هنوز سندی را وارد ۱۹.۱.۱ نمی‌کند.

## گزینه‌های بررسی‌شده

- **افزودن صفحه به برنامه‌ی ۱۹.۱.۱ الان:** رد شد؛ کاربر گفته انتقال ۱۹.۱.۱ اول انجام شود.
- **باز کردن همه‌ی درها (CORS برای همه):** رد شد. داده‌ی شخصی فقط باید برای صفحه‌ی خود کامپیوتر باشد.

## پیامد

- برای دیدن سندهای تازه باید `pull` اجرا شود. صفحه خودش نمی‌خواند، چون عبارت عبور را ندارد.
- سرور فقط روی `127.0.0.1` گوش می‌دهد؛ شبکه‌ی محلی به آن دسترسی ندارد.

## تأیید

- بک‌اند: ۹۲ تست، از جمله انتشار نتیجه به گوشی، عکس‌ها، ۴۰۴ برای عکس ناموجود، و CORS فقط برای مبدأ مجاز.
- در مرورگر با داده‌ی موقت: فهرست در دست بررسی، تأیید، دسته‌بندی سند ثبت‌سریع و انتقال آن به «در دست بررسی»، تب گزارش‌ها، و نمایش عکس‌ها. عرض صفحه در حالت دسکتاپ اضافه نداشت.
